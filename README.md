## Installation
### Prerequisites
- [Node.js](https://nodejs.org) 22 or newer
- [Yarn](https://classic.yarnpkg.com) 1.x (classic)

### App
```bash
# From the root of the repo
$ yarn install

# Run the app in development mode
$ yarn dev
```
